# Data Sources

The terminal standardizes every provider onto a canonical contract
(`app/data/catalog.py`): a daily gold OHLCV frame and an aligned macro/driver
frame, plus optional CFTC positioning and a news list. Providers are pluggable
and fail closed — on any error the data service falls back to the committed
sample snapshot, and a `LIVE / CACHED` badge reflects provenance.

## Providers (`app/data/providers/`)

- **`yahoo.py`** — keyless v8 chart endpoint; gold OHLCV + market-priced macro.
  `^TNX` is auto-scaled if quoted as yield×10.
- **`fred.py`** — official API when `FRED_API_KEY` is set, otherwise the keyless
  `fredgraph.csv` endpoint. Supplies the rates/inflation complex.
- **`cftc.py`** — best-effort CFTC disaggregated COT (managed-money long/short/net,
  open interest) for gold; degrades silently if the schema differs.
- **`news.py`** — RSS parsed with the standard library (no `feedparser`
  dependency); optional NewsAPI supplement.
- **`demo.py`** — loads the committed snapshot in `data_samples/`.

## Keys & modes

All keys are optional (`.streamlit/secrets.toml` locally, or the Streamlit Cloud
secrets manager): `FRED_API_KEY`, `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`,
`NEWSAPI_KEY`. `DATA_MODE` ∈ `auto` (live → snapshot fallback, default) / `live`
/ `demo`.

## The bundled snapshot

`data_samples/*.parquet` is a **synthetic, clearly-labelled** sample dataset
generated by `scripts/seed_samples.py`. The macro drivers are simulated first and
gold returns are constructed as a documented linear response to them plus noise,
so the analytics exhibit realistic structure offline. It exists purely so the app
renders without network access and so tests are deterministic; live providers
replace it automatically where data access is available.

## Caching & refresh

Live fetches are cached with `st.cache_data` (TTL: prices 15 min, macro 1 h, news
30 min). The sidebar **Refresh data** button clears the cache. Streamlit
Community Cloud filesystems are ephemeral, so caching is in-memory with the
committed snapshot as the durable floor.
